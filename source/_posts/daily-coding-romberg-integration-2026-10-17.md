# Romberg 积分 —— 用 Richardson 外推把梯形法逼近机器精度

## ① 背景与动机

> 你写了一个定积分 ∫ₐᵇ f(x) dx，梯形法把区间切成 4096 段，误差还有 3.65×10⁻⁹。换 Simpson 法，同样 4096 段，误差缩到 1.78×10⁻¹⁵。可这还不够——如果你要算到双精度浮点的物理极限，也就是 10⁻¹⁶ 这个数量级，有没有一种方法，几乎不增加函数求值次数，就能做到？

答案是：**Romberg 积分（Romberg Integration）**。它不是一个独立的求积公式，而是一个"方法升级外挂"——它拿最朴素的**复合梯形公式**当原料，用一套叫 **Richardson 外推（Richardson extrapolation）** 的数学技巧，把梯形法的误差**逐级消去**，最终逼近机器精度。我用它算 `exp(-x²)` 在 [0,1] 的积分，最终误差是 9.99×10⁻¹⁶，已经贴到了 `double` 能表达的极限。

在动手之前，先搞清楚这个问题的真实分量。数值积分（numerical integration / quadrature）是科学计算里最基础也最常被调用的底层组件。它的应用场景遍地都是：

- **物理仿真**：有限元法（FEM）里每个单元的内力，就是对一个形函数做高斯积分；天体力学里要算光线在引力场中的偏折路径，本质上是一维定积分。
- **渲染图形学**：蒙特卡洛路径追踪里，BSDF 的亮度积分、球谐系数（Spherical Harmonics）的投影，都是积分；甚至我前面几篇博客（球谐光照、IBL Split-Sum）里那些预计算的环境贴图，底层都是数值积分。
- **概率统计**：正态分布没有初等原函数，`Φ(x) = CDF` 的每一个值都是靠数值积分算出来的；金融里的期权定价（Black-Scholes）也依赖对概率密度积分。
- **信号处理**：DFT/FFT 本身就是积分的离散化，而频域滤波的反变换是数值积分。

**问题到底在哪？** 定积分 ∫ₐᵇ f(x) dx 解析可积的函数只占极少数。大多数现实里的 f(x) 要么没有初等原函数（`exp(-x²)`、`sin(x)/x`），要么原函数无比丑陋。于是我们退而求其次，用**采样 + 加权求和**的"求积公式"去近似：

```
∫ₐᵇ f(x) dx ≈ Σ wᵢ f(xᵢ)
```

朴素的思路是把区间 [a,b] 等分成 n 段，用矩形或梯形去盖住曲线下的面积。**但朴素方法的收敛速度慢得让人抓狂**：想让误差减半，梯形法得把段数翻倍，函数求值次数也跟着翻倍。对一个慢收敛的高精度要求，这是不可接受的浪费。

**Romberg 的核心洞见**是：与其傻傻地加采样点，不如把"误差本身"也当成可分析、可消除的对象。梯形法的误差有一个非常漂亮的数学结构和规律的展开形式（Euler–Maclaurin 公式），只要我们知道这个结构的系数关系，就能用**几组不同步长的梯形结果互相加减**，把误差项一个接一个地"消掉"。这就是 Richardson 外推的精髓，也是本文要讲透的东西。

这也是 Romberg 积分几十年来屹立不倒的原因：**实现极简（几十行代码）、精度极高（机器精度）、不依赖被积函数的光滑性以外的任何先验信息**。在需要高精度一维积分的确定性场景（不是蒙特卡洛那种赌随机），它至今仍是默认选择之一。

本文会完整走一遍：从复合梯形法的误差展开讲起，推导 Richardson 外推的递推公式，给出 Romberg 表的完整 C++ 实现，然后**用四个解析可积的函数做量化验证**——不仅看最终误差，还实测每一步的收敛阶，并用一个"端点奇异"的反例，展示 Romberg 方法的经典边界：当被积函数不够光滑时，外推会失效，而这恰恰是对理论的最好印证。

## ② 核心原理

### 2.1 定积分的切分与梯形法

给定 [a,b] 上的函数 f，把它等分成 n 段，步长 h = (b-a)/n，节点 xᵢ = a + i·h（i=0,…,n）。

**复合梯形公式（composite trapezoidal rule）**就是用 n 个梯形的面积之和逼近积分：

```
T(h) = h · [ ½ f(x₀) + f(x₁) + f(x₂) + … + f(x_{n-1}) + ½ f(xₙ) ]
```

这个式子的直觉就是：每段 [xᵢ, xᵢ₊₁] 上，把曲线 f 用连接两端点的直线代替，这一小块的近似面积就是梯形的 (f(xᵢ)+f(xᵢ₊₁))/2·h，全部加起来就是上式（内部节点因为被左右两个梯形共享，权重是 1；两端点各只属于一个梯形，权重是 ½）。

梯形法好实现、好理解，但精度是它的死穴：**误差是 O(h²)**。也就是说步长减半，误差只缩小到原来的四分之一。想要 10⁻¹⁶ 的误差，凭梯形法要切开十亿段，根本不可行。

### 2.2 Euler–Maclaurin 公式：梯形误差的本质

真正让 Romberg 方法成立的是下面这个定理——**Euler–Maclaurin 求和公式**（针对梯形法而言）：

**若 f 在 [a,b] 上充分光滑（2m+2 阶连续可导），则复合梯形法的误差可以展开为 h 的偶次幂级数：**

```
∫ₐᵇ f(x)dx − T(h) = C₂·h² + C₄·h⁴ + C₆·h⁶ + … + C_{2m}·h^{2m} + O(h^{2m+2})
```

**这是一个极其关键、但初学者常常忽略的性质**：梯形法的误差展开里，只有 h 的**偶数次幂**——h²、h⁴、h⁶……**没有任何 h、h³、h⁵ 这样的奇次幂项**。

这个"偶次幂"性质是哪来的？直觉上可以这样理解：梯形法是对称的（左右端点权重相等、内部等距），这种对称性会把误差展开里所有反对称的奇次项消掉。数学上它来自 Bernoulli 数 B₂ₖ 在 Euler–Maclaurin 展开中的系数结构——奇数阶 Bernoulli 数（除了 B₁）都是零，于是奇次幂项的系数跟着消失。

**这个"只有偶次幂"的结构，是后面一切外推的根基。** 如果误差里有 h³ 项，外推就只能消掉 h² 再消 h³，每次只能提一阶；但因为只有偶次幂，我们发现**一次外推能直接消掉 h²，把收敛阶从 2 跳到 4**，效率翻倍。这个结构之美，值得你停下来想一秒。

### 2.3 Richardson 外推：消掉误差项

现在有了关键展开式。设 T(h) 是步长 h 的梯形结果，T(h/2) 是步长减半（段数翻倍）的结果。分别写出：

```
I = T(h)   + C₂·h²     + C₄·h⁴    + …
I = T(h/2) + C₂·(h/2)² + C₄·(h/2)⁴ + …
```

注意两行里的 **系数 C₂、C₄ 是同一个 C₂、C₄**（因为它们只依赖 f 的导数在端点的值，与步长无关）。这是我们能消元的底气。

要**精确消去 h²**，正确的组合是：让两个结果按权重组合，使得 h² 项系数之和为零。设 I ≈ α·T(h) + β·T(h/2)，要求 α+β=1（保持一致性）且 α·C₂h² + β·C₂h²/4 = 0，即 α + β/4 = 0。联立解得 α = −1/3，β = 4/3。于是：

```
S(h) = (4·T(h/2) − T(h))/3
     = I + (C₄ 的某个倍)·h⁴ + O(h⁶)
```

**h² 项被彻底消掉了！** 新的组合 S(h) 的误差直接从 O(h²) 跳到 O(h⁴)。而这个 S(h) 你其实认识——**它就是复合 Simpson 公式**。所以 Simpson 本质上是"梯形法 + 一次 Richardson 外推"，这也解释了为什么 Simpson 是 O(h⁴) 精度。

我们可以继续：既然梯形误差只有偶次幂，那 Simpson 的误差也展开成 C₄h⁴ + C₆h⁶ + …，于是又能再做一次外推，消掉 h⁴，得到 O(h⁶)；再消 h⁶ 得 O(h⁸)……一路推下去，收敛阶 2→4→6→8→…，直到误差小到被浮点舍入误差淹没为止。

### 2.4 Romberg 表与递推公式

把上面的"逐级外推"系统化，就得到 **Romberg 表**。定义：

- `R(n, 0)` = 用 2ⁿ 段（即步长 h = (b-a)/2ⁿ）的复合梯形结果；
- `R(n, m)` = 在 `R(n, m-1)` 基础上做第 m 次外推的结果（误差 O(h^{2m+2})）。

**递推关系**（Romberg 方法的灵魂）只有两条：

**第一条：梯形列的递推（二倍细分工巧）**

```
R(0, 0) = (b-a)/2 · [f(a) + f(b)]
R(n, 0) = ½·R(n-1, 0) + h_n · Σ_{i 为奇数} f(a + i·h_n),   h_n = (b-a)/2ⁿ
```

第二条的妙处在于：从 2ⁿ⁻¹ 段到 2ⁿ 段，新增加的采样点恰好是"奇数下标"的那些点（i=1,3,5,…），而**旧的偶数下标节点都已经在 R(n-1,0) 里算过了**。所以每次翻倍细分，只需要算一半的新点，之前的所有求值结果全部复用。这是 Romberg 积分在实际中高性价比的根本原因——**它不像 Simpson/高斯那样每一步都要整表重算**。

**第二条：外推递推（消掉当前最低阶误差项）**

```
R(n, m) = R(n, m-1) + ( R(n, m-1) − R(n-1, m-1) ) / (4^m − 1)
```

这个式子怎么来的？本质上就是 2.3 节那个加权组合的推广：用 `R(n, m-1)`（步长 h）和 `R(n-1, m-1)`（步长 2h）两个外推级结果，按比例 `4^m : (−1)` 组合，消掉当前误差展开里的最低次项 h^{2m}。

分母的 `4^m − 1` 特别值得说道：它是从"步长比是 2"这个条件推出来的——我们每次都是步长减半，所以误差项里的 h^{2m} 在减半后变成 (h/2)^{2m} = h^{2m}/4^m，组合权重要让这两项抵消，分母自然就是 4^m − 1。**如果你用的不是二倍细分而是别的方式，这个 4^m 就会变成别的数。**

**直觉总结**：Romberg 表从左往右看，每一列都是一次"消掉最低阶误差"的化学提纯；从上往下看，每一步都是"采样点翻倍"。左上角是最粗糙的单个梯形，右下角（对角线 `R(n,n)`）是全局最精确的值，误差 O(h^{2n+2})，收敛阶 2n+2。

以 `exp(-x²)` 在 [0,1] 积分为例，我程序的真实输出里，梯形列（第一列）从 `0.68393972`（1 段）慢慢爬向真值 `0.74682413`，而外推列 `m=4` 在 `n=16`（32 段）时就已经给出 `0.7468241328`，跟 12 位有效数字，肉眼已经分不出差异了。这就是外推的威力。

### 2.5 为什么不用高斯求积？

读者可能会问：既然要精度，为什么不用 **Gauss–Legendre 高斯求积**？n 点高斯公式能以 2n−1 阶代数精度几乎"一步到位"。

理由有三：

1. **高斯求积没有优雅的误差估计**。高斯公式算完就一个数，你不知道它错多少；Romberg 表天然给出"外推前后的差值"作为误差指示器，可以据此自适应地决定是否继续细分。
2. **高斯节点不可复用**。想提高精度必须换一套全新的节点，之前算的 n 个函数值全浪费；Romberg 的梯形列是增量式的，翻倍细分只补一半新点。
3. **Romberg 把"逐步逼近"的过程显式化**，这对于要"按需精度"的自适应积分尤其友好。

高斯求积适合"我预先知道要几个点、一次算完"的场景；Romberg 适合"我不知道要多少精度，先算起来，逐步加密直到满意"的场景。两者互补，不冲突。这也是为什么很多通用积分器（如 QUADPACK 的 QAGS）内部其实是"自适应 Gauss–Kronrod"，但 Romberg 仍是教学与轻量实现的最优起点。

### 2.6 一个具体的数值走查（把抽象公式落到数字）

为了让你对"外推到底在做什么"有肌肉记忆，这里用 `1/(1+x²)` 在 [0,1] 的积分（真值 π/4 ≈ 0.78539816）走一遍前几步：

**第一步（1 段）**：单个梯形盖住整个 [0,1]，T(1) = ½·(f(0)+f(1)) = ½·(1+0.5) = **0.75**。误差约 −0.0354。

**第二步（2 段）**：新增中点 x=0.5，f(0.5)=0.8。T(2) = ½·0.75 + ½·0.8 = 0.375 + 0.4 = **0.775**。误差缩小到 −0.0104。

**第一次外推**：R(2,1) = 0.775 + (0.775 − 0.75)/(4¹−1) = 0.775 + 0.025/3 = 0.775 + 0.008333 = **0.783333**。看，误差一下子从 −0.0104 提到 −0.00206，**精度跃升了一个数量级**。

**第三步（4 段）**：新增奇数节点 x=0.25 和 x=0.75，f(0.25)=0.941176，f(0.75)=0.64。T(4) = ½·0.775 + ¼·(0.941176+0.64) = 0.3875 + 0.395294 = **0.782794**。

**第二次外推**：R(4,1) = 0.782794 + (0.782794−0.775)/3 = 0.782794 + 0.002598 = **0.785392**；继续 R(4,2) = 0.785392 + (0.785392−0.783333)/(4²−1) = 0.785392 + 0.002059/15 = **0.785529**。

到这一步，误差已经逼近 1.3×10⁻⁴。你看到规律了吗：**每一列都比上一列收敛更快，而这一切只用了区区 5 个函数求值**（x=0, 0.25, 0.5, 0.75, 1）。这就是 Romberg 把"廉价采样"变成"高阶精度"的魔法。

## ③ 实现架构

### 3.1 整体数据流

```
输入: [a,b], 被积函数 f, 最大细分层级 maxN, 最大外推级 maxM
        │
        ▼
   初始化 R(0,0) = (b-a)/2·(f(a)+f(b))       ← 单梯形
        │
        ▼
   for r = 1..maxN:                          ← 细分层级（2^r 段）
     ├─ 计算奇数节点和，得到 R(r,0)            ← 梯形列递推（复用旧值）
     └─ for m = 1..min(maxM, r):              ← 外推
           R(r,m) = R(r,m-1) + (R(r,m-1)-R(r-1,m-1))/(4^m-1)
        │
        ▼
   输出: Romberg 三角表 table[r][m], 最终值 table[maxN][maxM]
```

### 3.2 关键数据结构：三角表

我用一个二维 `std::vector<std::vector<double>>` 存整个 Romberg 表：

```
table[r][m]  = R(r, m)   // r: 细分层级(0..maxN), m: 外推级(0..maxM)
```

为什么存**整张表**而不是只存最后一列？因为：

- **对角线 `table[n][n]` 是全局最精确值**，需要整表才能取；
- **收敛阶测量**需要每一列在不同 r 下的误差序列（见 §⑥ 验证），存整表才能做；
- 内存开销微不足道（maxN×maxM 个 double，本例 13×13=169 个）。

这张表是**下三角**的：只有 m ≤ r 的表项有意义（外推级不能超过已有的细分层级），m > r 的表项我程序里保持为 NAN 并跳过。

### 3.3 CPU 侧职责划分（这题没有 GPU）

这是一个纯 CPU 的数值计算，没有渲染管线、没有 Shader。但职责划分依然清晰：

- **`romberg()` 函数**：纯算法，输入区间和函数对象，产出整张表，**不打印、不判验证**——保持单一职责，方便复用和测试；
- **`composite_trapezoid()` / `composite_simpson()`**：两个对照用求积函数，用来在验证环节做"同规模对比"；
- **`estimate_order()` / `estimate_order_of_first_column()`**：收敛阶测量工具，从误差序列反推实测幂次；
- **`TestCase` 结构体**：封装"被积函数 + 区间 + 解析真值 + 是否奇异"四个字段，把"算法"和"验证数据"解耦，加新测试用例不用改算法代码。

### 3.4 设计取舍

几个值得写下来的决定：

1. **用 `std::function<double(double)>` 传被积函数**。牺牲一点性能（有虚调用开销，内联不了），换来测试用例的自由组织。对一个教学/验证导向的程序，可读性优先于那点调用开销。
2. **梯形递推里只累加奇数节点**。这是 Romberg 高效的关键实现细节，见 §④ 的代码注释——它把翻倍细分的额外求值量从 O(2ⁿ) 降到 O(2ⁿ⁻¹)。
3. **收敛阶测量放在"末期倒数第二对"**。因为太早期的误差还没进入渐近区间，而最后一位可能被浮点舍入污染，倒数第二对最接近真实渐近斜率（代码里有注释解释）。

## ④ 关键代码解析

下面贴出核心代码，并逐段解释"为什么这样写"。完整可运行代码见项目仓库（`main.cpp`），但所有核心逻辑都在这里内嵌。

### 4.1 Romberg 表核心：一次求值 + 逐级外推

```cpp
static int romberg(double a, double b,
                   const std::function<double(double)>& f,
                   int maxN, int maxM,
                   std::vector<std::vector<double>>& table_out) {
    // table[r][m] = R(r, m)；r 是细分层级(2^r 段)，m 是外推级。
    table_out.assign(maxN + 1, std::vector<double>(maxM + 1, 0.0));

    // 基础情形：单个梯形，2^0 = 1 段
    double& r00 = table_out[0][0];
    r00 = 0.5 * (b - a) * (f(a) + f(b));

    for (int r = 1; r <= maxN; ++r) {
        int n = 1 << r;              // 2^r 段
        double h = (b - a) / n;
        double sum = 0.0;
        // 关键优化：只累加"新增"的奇数下标采样点
        for (int i = 1; i < n; i += 2) {
            sum += f(a + i * h);
        }
        // 梯形递推：R(r,0) = 0.5*R(r-1,0) + h * Σ_odd f
        table_out[r][0] = 0.5 * table_out[r - 1][0] + sum * h;

        // Richardson 外推，逐级提升精度
        for (int m = 1; m <= maxM && m <= r; ++m) {
            double denom = std::pow(4.0, m) - 1.0;
            table_out[r][m] =
                table_out[r][m - 1] +
                (table_out[r][m - 1] - table_out[r - 1][m - 1]) / denom;
        }
    }
    return 0;
}
```

**逐段为什么这么写：**

- `int n = 1 << r` —— 段数取 2 的幂，是因为 Richardson 外推的推导**依赖步长比恰好是 2**（见 §2.4 的 `4^m` 分析）。用 2 的幂能保证每次细分都是精确的减半，外推公式才严格成立。
- `for (int i = 1; i < n; i += 2)` —— 这是整个程序里**最容易被写错、也最值得记的一行**。从 2ⁿ⁻¹ 段翻倍到 2ⁿ 段，新节点的下标是 1, 3, 5, …, n−1（全是奇数）。偶数下标节点（被 2 整除的）在上一次迭代已经算过、已经累计进 `table_out[r-1][0]`。**如果写错成 `i++` 全累加，结果不会错，但代价是每次翻倍都重复算了所有旧点，白白浪费一半求值量**——这是新手最容易踩的性能坑。
- `table_out[r][0] = 0.5 * table_out[r-1][0] + sum * h` —— 梯形递推的数学含义：新梯形 = 旧梯形折半 + 新增奇数点贡献。注意前面乘 `0.5` 而不是简单相加，因为旧结果 `R(r-1,0)` 用的是步长 2h，换成步长 h 后它的贡献要重新按"面积"折算。
- `denom = pow(4.0, m) - 1.0` —— 外推的分母。**这是 Romberg 公式里最需要理解的一个常数**：`4^m` 来自"步长减半 → 误差项 h^{2m} 变成 (h/2)^{2m} = h^{2m}/4^m"，组合消元时自然出现。写成 `pow(4.0, m)` 而非位运算或查表，是为了可读性和对任意 m 的一般性；实际工程里若追求极致，可预先算好 `1/(4^m−1)` 的倒数表避免重复 `pow`。
- 边界 `m <= r` —— 外推级 m 不能超过细分层级 r（一个只切了 1 段的表，没法外推 3 次）。漏掉这个约束会读到 `table_out[r-1][-1]` 越界。

### 4.2 收敛阶测量：从误差序列反推幂次

```cpp
static double estimate_order(const std::vector<double>& errs,
                             const std::vector<int>& ns) {
    if (errs.size() < 3) return 0.0;
    // 用倒数第二对求斜率：末期最接近渐近行为，又避免末位被浮点舍入污染
    size_t k = errs.size() - 2;
    return std::log(errs[k] / errs[k + 1]) /
           std::log((double)ns[k + 1] / ns[k]);
}
```

**为什么这样写：**

- 收敛阶 p 的定义是 `err_k ≈ C · n_k^{-p}`。取相邻两项的比值再取对数：`log(err_k/err_{k+1}) / log(n_{k+1}/n_k)` 就是 p 的估计。
- `k = errs.size() - 2` 取**倒数第二对**，是经过考量的：太靠前（n 很小）时误差还没收敛到渐近幂次；而**最后一对**往往已经逼近机器精度，`err` 的下限被浮点舍入误差卡住，比值不再反映真实收敛阶，甚至可能算出负数（这正是我在 `sqrt(x)` 奇异用例里看到的 `-inf`——误差已经到 0 了，log(0) 爆炸）。倒数第二对是"既足够靠后体现渐近阶、又没被舍入污染"的甜点区。

### 4.3 奇异函数的外推退化测量

```cpp
static double estimate_order_of_first_column(
        const std::vector<std::vector<double>>& table, double exact) {
    std::vector<double> errs; std::vector<int> ns;
    for (size_t r = 2; r < table.size(); ++r) {
        errs.push_back(std::fabs(table[r][0] - exact));
        ns.push_back(1 << r);
    }
    return estimate_order(errs, ns);
}
```

这个函数专门用于**奇异端点**用例（`sqrt(x)`）的验证：当 Richardson 外推失效时，梯形列本身的收敛阶会从 2 退化到 ~1.5。我单独测第一列（梯形列，未外推）的收敛阶，就是为了**定量地**捕捉"外推失效"这一理论现象，而不是靠肉眼判断"好像没收敛"。

### 4.4 验证用的测试用例组织

```cpp
struct TestCase {
    std::string name;
    std::function<double(double)> f;
    double a, b;
    double exact;              // 解析真值
    bool singular_endpoint = false; // 端点奇异，Richardson 外推预期失效
};

cases.push_back({
    "exp(-x^2) on [0,1]",
    [](double x) { return std::exp(-x * x); },
    0.0, 1.0,
    0.746824132812427025,   // sqrt(pi)/2 * erf(1)
});
cases.push_back({
    "sqrt(x) on [0,1]   (端点奇异导数)",

    true   // 标记：期望外推退化
});
```

这里用 `singular_endpoint` 这个布尔标记来区分两类用例，验证环节据此走不同的判定分支（见 §⑥）。这个设计让"正常情形"和"理论失效情形"都能被**同一套程序自动判定**，而不是每次手动看输出。

## ⑤ 踩坑实录

写这个项目的过程里，我实实在在踩了几个坑，每一个都值得记录。以下每个都是"症状 → 错误假设 → 真实原因 → 修复"的完整闭环。

**坑 1：收敛阶测出了负数 / -inf**

- **症状**：`sin(x)/x` 用例的外推级 m≥2 收敛阶实测显示 `-inf` 甚至负值，而 m=0 梯形列却是漂亮的 2.000。
- **错误假设**：我以为"收敛阶为负"意味着外推代码写反了、误差在放大。
- **真实原因**：不是代码错了，而是**误差已经精确地到零**。看输出表，m≥2 的外推结果在 n≥32 时就精确等于真值到了 `double` 的最后一位，`err` 是 0 或 1e-16 量级，`log(0)` 直接是 `-inf`。这是**外推太快收敛到机器精度的表现，恰恰是算法成功的信号**。
- **修复**：把收敛阶的测量锚点从"最后一位"改到"倒数第二位"，避开被舍入误差截断的末点（见 §4.2 的 `k = size()-2`）。改完后 m=0/m=1 都得到干净的 2.000 / 4.081。

**坑 2：`sqrt(x)` 用例"看起来失败"，差点误删正确结果**

- **症状**：加了 `sqrt(x)`（端点 x=0 导数无穷）这个用例后，程序返回 exit code 1，显示"❌ Romberg 未显著优于梯形"，Romberg 误差 2.62e-07 甚至比朴素梯形还差一点点。
- **错误假设**：我第一反应是"我的外推代码对非光滑函数有 bug"。
- **真实原因**：这是**理论预言的正确行为，不是 bug**。`sqrt(x)` 在 x=0 的导数发散，Euler–Maclaurin 的"误差只有偶次幂"前提被破坏——误差展开里出现了**分数次幂 `h^{3/2}`**（因为 `sqrt` 的 Taylor 展开首项是 `x^{1/2}`）。Richardson 外推假设能消掉的是 `h²、h⁴…` 这些偶次项，面对 `h^{3/2}` 它无能为力，收敛阶从 2 退化为 1.5。我实测梯形列收敛阶 = 1.498，与理论 1.5 完美吻合。
- **修复**：不删这个用例，而是**把它当做一个"预期退化"的正向验证**：单独标记 `singular_endpoint=true`，判定逻辑改成"实测收敛阶落在 1.3~1.7 之间即通过"，从而把"外推失效"从事故变成了一次对理论局限性的确认。

**坑 3：`estimate_order` 的声明顺序导致编译失败**

- **症状**：`g++` 报 `error: 'estimate_order' was not declared in this scope`。
- **错误假设**：我随手把新函数 `estimate_order_of_first_column` 插在 `estimate_order` 定义之前，又让它内部调用后者。
- **真实原因**：C++ 里函数在使用前必须先声明或定义。我插的位置在 `estimate_order` 之前，编译器顺序扫描时还没见到它。
- **修复**：把 `estimate_order_of_first_column` 挪到 `estimate_order` 定义之后。教训：**依赖关系要顺着编译单元从上到下的顺序**，加辅助函数时先想清楚调用链。

**坑 4：收敛阶测量用哪一列，一开始拿错了数据**

- **症状**：想验证"外推失效"，却不知道测哪一列好。
- **错误假设**：起初我试图测外推列 `table[r][m]` 的收敛阶，结果一堆 `-inf` 无法解读。
- **真实原因**：外推失效的本质要落在**梯形列**（未外推的基准）的收敛阶上——因为失效来自"梯形误差展开不再是纯偶次幂"，这个性质直接体现为梯形列幂次从 2 掉到 1.5。测外推列只会得到外推后的混乱结果。
- **修复**：专门写 `estimate_order_of_first_column` 只测 `table[r][0]`，语义清晰。

### 6.1 解析真值对比（终极误差）

- 外推 m≥2：误差已到机器精度，阶次饱和（这正是收敛到极限的表现）

对奇异函数 `sqrt(x)`，梯形列收敛阶：

- 理论（退化后）：~1.5，**实测 1.498** ✅

**这组数据直接印证了 Euler–Maclaurin 偶次幂 + Richardson 消元的理论**：误差确实是按 `h² → h⁴ → …` 的偶数阶收敛的，奇异函数也确实退化为 `h^{1.5}`。

## ⑦ 总结与延伸

### 7.1 这个方法的核心贡献

Romberg 积分教给我的，不只是"怎么把积分算到机器精度"，更是一种**方法论**：**把误差当成一个有结构的、可分析的对象，而不是一团随机的噪声去忽视它。**

这句话值得展开。在几乎所有数值方法里，"误差到底怎么来、以什么速度消失"是决定一个算法能不能用的根本问题。梯形法之所以是"低阶方法"，不是因为它的公式难看，而是因为它的误差是 O(h²)——收敛太慢。而 Romberg 的厉害之处在于，它**没有换更复杂的公式**，只是通过观察"误差是 h 的偶次幂"这个规律，就用极小的代价把误差逐级消掉。这背后是一种更高级的思维：**与其硬磕更精确的近似，不如利用算法的误差结构去"反推"真相。**

这套"外推"思想并不止于积分。同样的 Richardson 外推思想，可以迁移到：

- **数值微分**：前向差分是一阶精度，用外推能把差分逼近的阶数成倍提高（这正是有限差分里"逐级外推"的做法）；
- **常微分方程求解**：我之前写的 RKF45（见 10-16 的博客）里，"4 阶与 5 阶嵌入对做差得误差估计"，本质上是同一个"用两个不同阶的近似做差来估计误差"的思想；
- **序列极限加速**：Aitken Δ² 加速就是 Richardson 外推在标量序列上的特例。

所以 Romberg 积分是一个绝佳的"思想载体"：它让你真正理解"误差结构"和"外推"这两个贯穿整个数值分析的主题。

### 7.2 这个方法的局限性

Romberg 也不是万能药，它的适用边界很清楚，这里必须诚实交代：

1. **要求被积函数充分光滑**。只要 f 在积分区间内部或端点出现奇异性（导数发散、不连续、振荡），Euler–Maclaurin 的偶次幂展开就会失效，外推跟着失效。本文的 `sqrt(x)` 用例正是这个极限的活教材：收敛阶从 2 跌到 1.5，外推几乎白做。
2. **对高振荡函数不友好**。像 `sin(100x)` 这种高频振荡的被积函数，梯形法需要切到比振荡周期更细才能开始收敛，Romberg 的"翻倍细分"策略在达到足够分辨率之前是徒劳的。这类问题更适合用高斯型或专门的振荡积分方法（如 Filon 方法）。
3. **维度灾难**。本文只讨论一维。到了高维积分（如 3D、10D），"翻倍细分"的策略会让计算量按维数指数爆炸，Romberg 完全不可行，那时候就得靠蒙特卡洛 / 准蒙特卡洛（我之前写过的 Halton 序列 QMC 就是干这个的）。
4. **内存与递推的耦合**。Romberg 表要共存多级结果，虽然内存小，但它是"批处理式"的——不适合"自适应地在一小片区域加密"这种精细化需求。自适应 Simpson / Gauss–Kronrod 在"被积函数某处剧烈变化"的问题上更灵活。

### 7.3 可以继续优化的方向

顺着本文的代码，至少有这几个值得继续深挖的方向：

1. **自适应终止**：本文固定跑满 maxN 层。工程上可以根据"外推前后 `R(n,n)` 与 `R(n,n-1)` 的差值是否小于容差"来自动停表，避免白算。这正好用到了 §2.5 提到的"外推自带误差指示器"。
2. **预计算倒数表**：把 `1/(4^m−1)` 预先生成到数组，替代每步 `pow(4.0,m)`，在高频调用或更大 maxM 时减少常数开销。
3. **处理端点奇异**：对 `sqrt(x)` 这类已知端点奇异，可以先做变量替换（如 x = t² 吸收奇异），把问题变成光滑的再交给 Romberg——这是数值积分里经典的"去奇异（singularity elimination）"思路，能让 Romberg 重新恢复满速收敛。
4. **多区间组合**：把积分区间分段，每段各自 Romberg，用于"区间内某处不光滑但分段后可光滑"的情况。

- **09-01 FFT**（Cooley–Tukey）、**09-30 自适应 Simpson**、**10-01 Gauss-Seidel/Jacobi**、**10-16 RKF45**，都是数值分析的具体工件；
- 本文的 Romberg 与 **09-30 自适应 Simpson** 是"亲兄弟"——两者都从梯形法/Simpson 出发，只是 Romberg 走"全局外推、逐级提阶"的路线，自适应 Simpson 走"局部加密、误差控制"的路线；
- 本文 §2.3 揭示了"Simpson 就是梯形 + 一次外推"，这个事实反过来也让 09-30 的 Simpson 有了更深的理论注脚；
- "误差指示器 → 自适应"的思想，与 **10-16 RKF45** 里"嵌入对做差 → 自适应步长"如出一辙，同属"用廉价近似之差估计误差"这一族方法。

如果读者正在系统地过一遍数值分析，我建议把 Romberg 和自适应 Simpson 放在一起对照着实现、对照着验证，你会对"误差结构"这个概念建立起肌肉记忆——而这正是从"会调用数值库"进阶到"能设计数值算法"的分水岭。
